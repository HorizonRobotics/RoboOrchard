# Wuji Hand 2 interfaces

Unmodified Hand 2 interfaces from
[wuji-ros2 v2026.10.26](https://github.com/wuji-technology/wuji-ros2/tree/v2026.10.26/wuji_msgs),
licensed under MIT (see [LICENSE](LICENSE)). Only the three messages and five
services used by `robo_orchard_wuji2_ros2` are included. Names, fields,
fixed-array lengths and units retain the official contracts.

This package occupies the official `wuji_msgs` package name. Do not put another
copy of `wuji_msgs` in the same workspace. Unrelated official Glove interfaces
are not included; RoboOrchard Glove uses `robo_orchard_wuji_glove_msg_ros2`.
